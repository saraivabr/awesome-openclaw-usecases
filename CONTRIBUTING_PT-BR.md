# Contribuindo

## Adicionando um Caso de Uso

1. Crie um arquivo markdown na pasta `/usecases` (e opcionalmente sua versão em português em `/usecases/pt-br`) com o nome do seu caso de uso.
2. Adicione os detalhes do seu caso de uso. Aqui estão alguns tópicos recomendados para cobrir:
   - **Ponto de Dor (Pain Point)** — Qual problema isso resolve?
   - **O Que Ele Faz (What It Does)** — Breve explicação do caso de uso
   - **Prompts** — Os prompts ou configurações reais que você forneceria ao OpenClaw
   - **Habilidades Necessárias (Skills Needed)** — Quais skills do OpenClaw são requeridas
   - **Links Relacionados (Related Links)** — Documentação relevante, APIs e ferramentas
3. Adicione uma linha à tabela da categoria correspondente no [README.md](README.md) (e no [README_PT-BR.md](README_PT-BR.md))
4. Abra um Pull Request (PR)

## Diretrizes

- Apenas um caso de uso por arquivo markdown
- Mantenha as descrições concisas, porém com detalhes suficientes para replicação
- Se o seu caso de uso não se encaixar em uma categoria existente, sugira uma nova categoria no seu PR
- Casos de uso similares são aceitos desde que a abordagem seja significativamente diferente
- Não use IA para inventar novos casos de uso sem testar. Sugira apenas casos de uso que você realmente testou e verificou
- **Sem casos de uso relacionados a criptomoedas especulativas** — estes não serão aceitos.
