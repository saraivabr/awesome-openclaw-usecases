# Awesome OpenClaw - Casos de Uso

> **⚠️ Aviso sobre a versão em Português**  
> Este documento é uma versão traduzida pela comunidade para Português do Brasil. Para a referência mais recente em inglês, consulte o [README.md original](README.md).

---

Resolvendo o gargalo da adoção do OpenClaw: não são as ~~skills~~, mas sim encontrar **formas práticas de melhorar a sua vida**. Esta é uma coleção comunitária de casos de uso reais para o [OpenClaw](https://github.com/openclaw/openclaw).

> **Aviso:** As skills do OpenClaw e dependências de terceiros aqui citadas podem conter vulnerabilidades críticas de segurança. Vários casos de uso apontam para skills, plugins e repositórios externos desenvolvidos pela comunidade que **não foram auditados pelos mantenedores desta lista**. Sempre revise o código-fonte de qualquer skill, examine as permissões solicitadas e evite deixar chaves de API ou credenciais expostas no código. Você é o único responsável pela sua própria segurança.
